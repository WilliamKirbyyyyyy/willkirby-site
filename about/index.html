About

Hi, I’m Will.

I’m a student and indie developer, and the founder of Kirby Systems. I’ve been building and selling software for several years. RIVET started as a PowerShell script and is now a native Windows app on the Microsoft Store.

I’m at Blundell’s School, where I’m an Academic Scholar and a DT Scholar. I’m aiming at computer science, electronics and business, with a growing pull towards quantitative work.

I learn by shipping. Alongside the code there are microcontrollers, CAD and 3D printing.
