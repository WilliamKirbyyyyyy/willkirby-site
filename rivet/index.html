RIVET.

A native Windows system manager that started life as a PowerShell script. This is how it was designed and built, and the problems that only showed up once real people could install it.

01 — The story

A script that kept growing up.

  1. 1.0

    Jarvis

    A personal productivity tool. Never shipped, but it started everything.

  2. 2.x

    PowerShell

    Thousands of lines in a single script. Released on itch.io in Free, Lite and Pro tiers: 136 downloads. Source on GitHub

  3. 3.0 – 3.3

    Native app

    Rebuilt from scratch in C# with .NET 10 and WPF. Live on the Microsoft Store since July 2026.

  4. 3.5

    Guard & rollback

    Eleven new features, including a first-run checkup, Guard & Restore and roll back to a date.

  5. 3.6 — Now

    Ten languages, four looks

    Translated into nine more languages, with four new themes that each have their own layout, all meeting WCAG AA contrast.

02 — Design

Four directions before one line of UI.

Before writing any interface code I mocked the same screen in four very different visual styles, to decide what RIVET should feel like rather than defaulting to the first idea.

03 — Build

Ten milestones, each one runnable.

RIVET 3 was built in ten milestones, written to a spec, with the core logic covered by automated tests. Each milestone had to run before the next one started.

  1. M1

    The shell

    An empty window with the navigation, theme and command bar in place before any features: the frame everything else hangs on.

  2. M2

    Live HUD, processes and services

    Real CPU, memory, GPU, disk and network readings once a second, plus process and service lists with signed-publisher checks.

  3. M3

    Startup manager

    Every app that launches with Windows, how much it slows startup, and a safe way to delay or disable it.

  4. M4

    Cleanup and tweaks

    Reclaimable space by category and plain-English Windows settings, each one reversible.

  5. M5

    Focus sprint

    A pomodoro-style sprint ring that can lock distractions for the length of a session.

  6. M7

    Command console

    A keyboard-first console: type a command instead of clicking through screens.

  7. M8

    Ask RIVET

    A local AI that answers questions about your PC using the app's own live readings, with nothing sent off the machine.

Not pictured: M6 tasks, deadlines and progression (with an importer for RIVET 2.x data), M9 licensing and the free trial, and M10 packaging and Microsoft Store certification.

04 — Problems solved

The bugs that only real installs find.

Packaging

Tweaks that silently did nothing

Store apps run in a container that quietly redirects registry writes. Every tweak looked applied but changed nothing. I proved it by measuring on the installed Store build, not by reading code. When Store review refused the standard opt-out twice, I found a fix that works within the rules.

Local AI

Measured, not guessed

Ask RIVET moved from a separate local AI server to an engine bundled in the app, with a model download that only happens if you agree. That's the single network connection RIVET makes. I built an evaluation harness and let the results decide; one technique stayed switched off because the numbers showed it made answers worse.

Real hardware

One Wi-Fi card, seven times

Windows lists a network adapter once per filter driver attached to it, so a single Wi-Fi card showed up seven times with a nonsense link speed. Tests passed; a real machine didn't. RIVET now works out which adapters are real.
